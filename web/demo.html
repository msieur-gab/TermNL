What this is

TermNL lets you talk to a Linux board in plain words. This is TermNL itself, running in this page, on a pretend board with a few folders. Commands are shown, never run: nothing on your computer is touched.

Every request ends in one of four outcomes: act, ask, approve, abstain. The code and how it works

It asks when it isn't sure
It says when it doesn't know

A skill is a text file. Change this one, or write your own, then teach it.
