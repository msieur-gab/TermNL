# File types

A shared list of values: written by skill authors, not supplied by the device.
Each line: the type, its extensions (the first is the one a new file gets), then the words people use
for it. Plurals are written out: "images" is a word of its own.

- markdown (md): markdown, md
- text (txt): text, txt, plain text
- python (py): python, py, script
- html (html): html, web page, webpage
- csv (csv): csv, table, spreadsheet
- note (md, txt): note, notes
- pdf (pdf): pdf, pdfs
- image (jpg, jpeg, png, gif, webp, svg): image, images, photo, photos, picture, pictures, pic, pics
- video (mp4, mkv, webm, mov, avi): video, videos, movie, movies, film, films, clip, clips
